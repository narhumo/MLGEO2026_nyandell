# How to Clone

I am assuming you have git installed. If you don't have it installed and authorized, do so now.

Once you have git, please run the following to clone this repo and install pixi:

```
git clone https://github.com/narhumo/MLGEO2026_nyandell
pixi install 
```


# How to Run

smoke_test.py:  This repository's smoke test, to determine if the environment is functioning. Tested on a Darwin arm64. To run, please type this into your terminal when in the directory:
```
pixi run smoke
```

To run any notebooks (such as HW1_TestNotebook), please use the following in terminal after downloading the repo and navigate to the desired file(s).
```
 pixi run jupyter lab
```
